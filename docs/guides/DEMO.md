# DualVibe Coding 演示流程

录公开演示时按这个走就行。不要带上个人应用、映射或路径。

1. 打开 DualVibe Coding，先看顶部是不是已经连上 DualSense，电量和充电状态对不对。
2. 到「连接与语音」页，看手柄列表、输入电平、麦克风选择和灵敏度。
3. 到「按键映射」页，切一下正面/背面视角，展示触控板和摇杆映射，以及鼠标单击、双击和长按。
4. 打开一个映射编辑器，录一条快捷键，并选一下左右修饰键。
5. 到「权限」页，看辅助功能、输入监控和麦克风的状态。
6. 从访达把一个公开的测试 App 拖进应用库，确认卡片出现后再把它删掉。
7. 打开快捷轮盘，用方向键或摇杆移动选择，按确认执行，按取消关掉。

录的时候只用干净的测试配置。个人应用名、映射内容、系统路径、签名密钥或聊天窗口，都不要进入公开素材。
