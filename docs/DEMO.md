# DualVibe Coding 演示流程

这份流程用于录制公开演示，不包含个人应用、映射或路径。

1. 启动 DualVibe Coding，确认顶部显示已连接的 DualSense、电量和充电状态。
2. 在“连接与语音”页展示手柄列表、输入电平、麦克风选择和灵敏度调节。
3. 在“按键映射”页展示正面/背面视角、触控板和摇杆映射，以及鼠标单击、双击和长按动作。
4. 打开一个映射编辑器，展示快捷键录入和左右修饰键选择。
5. 在“权限”页展示辅助功能、输入监控和麦克风状态。
6. 从 Finder 把一个公开的测试 App 拖入应用库，确认卡片出现后移除测试项。
7. 打开快捷轮盘，使用方向键或摇杆移动选择，按确认键执行，按取消键关闭。

录制时只使用干净的测试配置。不要把个人应用名称、映射内容、系统路径、签名密钥或聊天窗口放入截图和视频。
